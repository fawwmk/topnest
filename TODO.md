# План разработки виджета для macOS

Этот файл — рабочий маршрут проекта. Выполненные пункты отмечаются `[x]`, текущий этап — пометкой **Сейчас**, новые решения и ограничения дописываются в соответствующий раздел.

## Принципы проекта

- [ ] Нативное приложение на SwiftUI и AppKit без сторонних зависимостей.
- [ ] Минимальная версия системы — macOS 15.
- [ ] Приложение работает на MacBook как с физической чёлкой, так и без неё.
- [ ] На Mac без выреза используется виртуальная зона по центру верхнего края экрана.
- [ ] В свёрнутом состоянии приложение почти не расходует CPU и не мешает другим окнам.
- [ ] Разрешения запрашиваются только в момент использования соответствующей функции.
- [ ] Приватные API изолируются и имеют запасной безопасный сценарий.
- [ ] Пользовательские данные хранятся локально.

## Решения, которые нельзя потерять

- Frame окна не анимируется: анимируется только содержимое внутри панели.
- Прозрачность не обеспечивает сквозные клики; для этого переключается `ignoresMouseEvents`.
- Положение курсора читается независимо от активности приложения.
- Вкладки переключаются только после выдержки наведения.
- Окно не забирает клавиатуру, пока пользователь не открыл функцию с вводом текста.
- Полка удаляет только карточку, а не оригинальный файл.
- История буфера никогда не сохраняет concealed-данные.
- Перевод полностью локальный.
- Календарь — единственное штатно необходимое системное разрешение.
- Модуль Now Playing считается экспериментальным и не должен влиять на устойчивость остальных функций.
