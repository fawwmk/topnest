# TopNest

Нативная скрытая панель для macOS, которая раскрывается из верхней центральной области экрана. Проект написан на SwiftUI и AppKit без сторонних зависимостей.

## Требования

- macOS 15 или новее
- Swift 6 / Xcode Command Line Tools

## Сборка

```sh
./Scripts/bundle.sh
open build/TopNest.app
```

Текущий статус разработки находится в [TODO.md](TODO.md).

## Ограничения системного плеера

macOS не предоставляет публичного API для чтения активного трека другого
приложения. TopNest изолирует работу с приватным `MediaRemote` в отдельном
helper-процессе и не запрашивает Automation или Accessibility. Apple может
изменить этот механизм в обновлении macOS; в таком случае вкладка плеера
покажет недоступное состояние, не затрагивая остальные функции.

Из-за использования приватного API эта версия системного плеера не подходит
для распространения через Mac App Store.
