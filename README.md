# TopNest

Нативная скрытая панель для macOS, которая раскрывается из верхней центральной области экрана. Проект написан на SwiftUI и AppKit без сторонних зависимостей.

## Требования

- macOS 15 или новее
- Swift 6 / Xcode Command Line Tools

## Сборка

```sh
./Scripts/bundle.sh
open build/TopNest.app
```
